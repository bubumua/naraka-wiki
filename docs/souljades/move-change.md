# 招式魂玉

招式魂玉是指改变原武器或原动作的魂玉。以下分近战武器魂玉、远程武器魂玉、其他招式魂玉分别进行介绍。

武器魂玉仅作用于特定武器，通常会改变某些招式的效果，或者增加一些新的效果。部分武器魂玉可以**升华**，即达成特定条件后会获得额外的效果。

- 略：50\%及以下
- 无修饰：50-100\%

带\*表示蓄力动作会发生改变，\*个数越多优先级越高。
