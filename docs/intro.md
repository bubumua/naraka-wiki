# 游戏介绍

永劫无间是一款由24 Entertainment开发的冷兵器格斗大逃杀游戏，玩家在游戏中利用各种武器和技能与其他玩家进行战斗，成为最后的幸存者。游戏融合了武侠元素和现代设计，提供了丰富多样的角色选择和战斗策略。玩家可以选择不同的角色，每个角色都有独特的技能和战斗风格。游戏中有多种武器可供选择，包括长剑、太刀、弓箭等，每种武器都有不同的攻击方式和战斗策略。永劫无间还提供了多种游戏模式，包括天选之人（其下又分为多种大逃杀模式和娱乐模式）、征神之路（PvE模式）、无间镖客（搜打撤模式），玩家可以根据自己的喜好选择不同的游戏方式。游戏的画面精美，音效逼真，提供了沉浸式的游戏体验。无论是喜欢单人挑战还是团队合作的玩家，都能在永劫无间中找到乐趣和挑战。

## 游戏安装

在国内，永劫无间在多个平台上提供下载和安装，包括官方、Epic 和 Steam。多个平台账户之间不互通，但是在游戏匹配时统一匹配，不分平台。玩家可以在游戏内正常与其他平台的玩家进行交友、匹配和对战。玩家可以根据自己的喜好选择适合的平台进行下载和安装。
