# 减伤机制

## 一、 减伤计算核心规则

官方的减伤计算规则，核心逻辑为**“同源相加，异源相乘”**：

- **同源叠加与上限：** 相同来源的减伤属性相互叠加（加算），但无论如何叠加，**单一类别的减伤上限为 90%**。
- **异源乘算：** 不同来源的减伤属性进行乘算。

**官方举例说明：**

- **同源溢出：** 顾清寒开启【冰决】时有 70% 的【奥义技能减伤】。若队友释放【不动如山】增加 35% 的【奥义技能减伤】。两者同源相加为 105%，但由于上限设定，顾清寒最终的奥义减伤仅为 90%，受到 10% 的伤害。
- **异源乘算：** 顾清寒同时具有 10% 的【道具减伤】和 10% 的【天赋技能减伤】。最终承受伤害为：`(1 - 10%) * (1 - 10%) = 81%`（即总减伤为 19%）。

------

## 二、 目前游戏中的 7 种减伤分类

目前游戏内的减伤效果严格分为以下 7 种，这 7 种来源之间互为**乘算关系**：

1. **道具减伤**（例如：神像-玄武、各种减伤果子）
2. **魂玉减伤**
3. **技能减伤**
4. **奥义减伤**（注意：仅指开大时的奥义金霸体减伤）
5. **武器减伤**（可以与天赋中的武器减伤叠加）
6. **天赋减伤**
7. **特殊状态**（例如：磐石、岳山、沈妙、振刀处决等）

------

## 三、 各类减伤机制的具体测试与细节

### 1. 异源乘算实例展示

如果玩家在开大时拥有 70% 的奥义减伤，此时队友胡桃给你套了一个“庇护·守”（属于其他类别减伤，按 70% 举例计算），那么你受到的伤害为： `1 * (1 - 0.7) * (1 - 0.7) = 0.09`，即只受到 9% 的伤害。

### 2. 奥义减伤的常见误区

所谓“奥义减伤”，**只有在角色开启大招的那一下瞬间（金霸体状态）才存在**，并不是开启大招后持续存在的增益。

### 3. 技能减伤的判定

像胡桃的“急疗”以及特木尔/岳山的“战吼”等效果，在系统中都被计算在 **“技能减伤”** 这一类别中。

- 在视频 [^1] 的极限测试中，叠加庇护·守、急疗、捏蓝和魂玉，减伤幅度可以直接拉到惊人的 **95%**。

### 4. 道具减伤的叠加

不同的道具减伤是可以互相叠加的。例如，激活“玄武”神像并吃下两种不同的减伤果子，减伤效果可以达到 **40%**。

### 5. 特殊状态减伤详解

属于“特殊状态”的减伤机制有其独立的判定规则，且都只会与其他类型进行**乘算减伤**：

- **阔刀/斩马刀的磐石：** 磐石效果**不受**天赋里武器减伤的加持。但是，它会受魂玉等其他减伤效果的影响（乘算关系）。
- **英雄自带减伤：** 岳山自带的远程减伤、沈妙机甲自带的减伤。
- **处决减伤：** 成功振刀后进行处决时的 **70% 减伤**。
