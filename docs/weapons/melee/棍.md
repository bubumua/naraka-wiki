# 棍

左蓄前3击不可自由调整方向，后4击可自由转向[^1]

右蓄第3击可通过长/短闪取消。

定海针击中后的两下是蓝刀，后面的4+4下才是金刀；若为击中，则后面的2+4下都是蓝刀

## 连招

钩索蓄力：升龙-钩索-右蓄

升龙二连：升龙-a1-a2-跳a
当有少林棍时，升龙-a1-a2-b3

升龙钩索二连：升龙-钩索-a1-a2-跳a
当有少林棍时，升龙-钩索-a1-a2-b3
注意，加入钩索时，a1要视情况慢出，否则a2少刀，导致后续招式无法衔接。

[^1]:个人测试，可能因硬件不同而有所偏差
