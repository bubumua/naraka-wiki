# 阔刀

重刃的招式循环和非重刃不太一样。。非重刃武器，无论上一招是a1还是b1，直接按攻击键a/b，下一招一定是a2/b2；无论上一招是a2还是b2，点按攻击键a/b，下一招一定是a3/b3。但重刃的衔接大多取决于上一招是什么，a/b之间并不相同。

因此有a1-a2，b1-a2之分，亦有b1-b2，a1-b2之分。当然他们都是蓝刀。

a1-a2是横着来两下，先向左后向右，本文称为狂潮（命名取自斩马刀）。两刀都可以打到倒地敌人。

b1-a2是从右往左来一下，本文称为横劈。打不到蹲伏敌人。

a1-b2是从下往上来一下，本文称为上撩。

b1-b2是从上往下来一下，本文称为下撩。



狂潮-a（白刀）形如a1，也打不到倒地敌人，但可以打到蹲伏敌人，伤害稍低一些，本文称为次a1 441

狂潮-b形如下撩，伤害更高，本文称为下斩697

b1-a2-a招式方向和狂潮相反，本文称为逆狂潮774=387\*2

b1-a2-b=b1

b1-b2-a为次a1

b1-b2-b=b1

a1-b2-a招式动作和横劈相反，本文称为逆横劈616，打不到蹲伏敌人

a1-b2-b为下斩697



次a1-a为狂潮

次a1-b为下斩



下斩-a为次a1

下斩-b为b1

## 蓄力

阔刀除了左蓄（旋风斩，也叫大风车），和右蓄（崩山斩），还有另一套蓄力体系，即某些招式后按住右键蓄力。这种类型蓄力招式和右蓄类似，但少了前半段上撩的过程，因此本文称为半丘斩/半山斩。这两个差不多，就伤害有所区别。斩马刀则没有这套蓄力体系。
