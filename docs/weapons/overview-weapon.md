# 武器概览

永劫无间中的武器分为近战兵器和远程兵器两大类。近战兵器包括长剑、链剑、横刀、太刀、扇、匕首、双截棍、棍、阔刀、斩马刀、双戟、拳刃、枪、双刀、飞刀和万刃轮，每种武器都有其独特的攻击方式和连招。远程兵器则包括弓箭、鸟铳、五眼铳、双铳、连弩、火炮、一窝蜂等。玩家可以根据自己的喜好和战斗需求选择合适的武器进行战斗。

## 近战兵器

近战兵器中有些武器之间互为**同源武器**。互为同源武器的两种武器通常白刀招式相同，但其他攻击方式或机制有所差异。同源武器之间可以通过消耗锻造锤进行转化。例如长剑和链剑就互为同源武器，统称为双刃，可以在货郎处购买锻造锤进行转换。非同源武器则不可使用锻造锤转换转化为其他武器。

同源列表：

- 双刃：长剑和链剑
- 单刃：太刀和横刀
- 短持：匕首和扇
- 双持：双刀和双戟
- 重刃：阔刀和斩马刀
- 长兵器：长棍和长枪

其余武器均无同源武器：

- 双截棍
- 拳刃
- 飞刀
- 万刃轮（该武器仅有概率在飓风客中获取）
